# Agent City

Webtoon/manhwa adaptation workspace for **Agent City**.

The project reformats the original 10-page comic into a mobile-first vertical narrative. The canonical unit is a **case**: one generated/validated visual beat at a time. Approved cases are immutable inputs to later assembly.

## Working rule

- one generation = one case/visual beat;
- continuity and story logic beat isolated visual beauty;
- once a case is approved, do not regenerate it;
- assemble approved cases deterministically on a white vertical canvas;
- source material, continuity decisions, production rules, approved assets and optional rushes/bloopers live in this repository.

See `AGENTS.md`, `bible/`, and `storyboard/chapter-01.md`.
